# Interfaces

uHistorian possède plusieurs interfaces d’acquisition de données en provenance de différentes sources tel que des composants IoT, des automates programmables ou autres sources de données.

Les interfaces actuellement disponibles sont:

- Composants Yoctopuce: Jusqu'à 21 composants Yoctopuce pour la mesure de signaux ([Yoctopuce, USB sondes et actuateurs](http://www.yoctopuce.com) )

- Interfaces OPC-UA Client et Serveur

- LIDAR - RS485

- OpenWeather: Site de données météorologiques localisées (avec coordonnées long/lat)
