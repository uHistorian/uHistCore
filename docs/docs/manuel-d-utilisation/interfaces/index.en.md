# Interfaces

uHistorian has several data acquisition interfaces for data coming from different sources, such as IoT components, programmable controllers or other data sources.

The interfaces currently available are:

- Yoctopuce components: up to 21 Yoctopuce components for signal measurement ([Yoctopuce, USB sensors and actuators](http://www.yoctopuce.com))

- OPC-UA Client and Server interfaces

- LIDAR - RS485

- OpenWeather: localized weather data site (with long/lat coordinates)
